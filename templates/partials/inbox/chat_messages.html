The guard reads template_id, the integer column Django keeps beside the relation, so a message with no plantilla costs no query. Every view that renders this partial builds chat_messages through core.views._thread_context, whose select_related("template") joins the plantilla into the same query, so message.template.name fetches nothing extra either. billed_amount is a Decimal, or None when nothing was billed. The inner if is falsy for None and for a zero amount alike, so only a real charge prints; floatformat:4 shows it with four decimals, because per-message rates are fractions of a cent. Deleting a plantilla sets template_id to NULL on its messages (the ForeignKey is on_delete=SET_NULL), which removes this badge from them although the billing columns stay.
