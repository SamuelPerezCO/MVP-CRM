{% comment %} The "¿Cómo quieres crear tu plantilla de WhatsApp?" chooser -- opened by both create buttons (toolbar and empty state) via data-dialog-open. A native on the shared `.modal` shell (modal.css): showModal() supplies the focus trap, Escape handling and focus return natively (the explicit aria-modal below is belt-and-braces for older assistive tech); shell.js adds backdrop-click close (opt-in via data-dialog-backdrop-close) and closes the dialog once a card's HTMX request succeeds (data-close-on-success). The .modal__body wrapper scrolls on short viewports so the X stays pinned. Each card is one link -- the whole surface is clickable and the "button" inside is a styled span, so keyboard users get a single Tab stop per card. The solid/outlined pairing is deliberate: "desde plantilla" is the recommended path. Context: (none) {% endcomment %}
