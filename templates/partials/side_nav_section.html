{% comment %} Reusable nav section -- one titled group of rows in a screen's secondary nav (column 2). Mi comercio includes it four times; any screen with a multi-section nav can reuse it the same way. Two renderings, picked by the ``flat`` parameter: * default (collapsible) -- native
/ rather than JavaScript: it toggles, is keyboard operable and announces its expanded state to assistive tech for free, and still works if JS never loads. Each include is its own
, so sections expand and collapse independently. The chevron is one glyph rotated by CSS on [open]; all sections start collapsed, showing only their title until the user opens them. * flat=True -- the same title and rows as a plain, always-open group: no chevron, nothing to toggle. Campañas mounts the account nav this way. The child rows themselves live in partials/side_nav_rows.html so both renderings share one source. The styling lives on the shared `.side-nav` classes (embudos.css, with the collapsible extension in automatizaciones.css). Parameters (pass via {% include ... with %}): section -- has .icon_template, .title and .views (key, label) active_view -- key of the currently selected view section_key -- the sidebar slug, e.g. "mi-comercio" (for href/push-url) panel_url_name -- URL name resolving to the panel endpoint panel_target -- id of the column-3 element the rows swap, no "#" flat -- optional; True renders the non-collapsible variant {% endcomment %} {% if flat %}
