{% comment %} Reusable collapsible nav section -- one titled, chevroned group of rows in a screen's secondary nav (column 2). Mi comercio includes it four times; any screen with a multi-section nav can reuse it the same way. Collapsing uses native
/ rather than JavaScript: it toggles, is keyboard operable and announces its expanded state to assistive tech for free, and still works if JS never loads. Each include is its own
, so sections expand and collapse independently. The chevron is one glyph rotated by CSS on [open]; all sections start expanded. Each child row is a real link that HTMX upgrades into a swap of column 3 only. The styling lives on the shared `.side-nav` classes (embudos.css, with the collapsible extension in automatizaciones.css). Parameters (pass via {% include ... with %}): section -- has .icon_template, .title and .views (key, label) active_view -- key of the currently selected view section_key -- the sidebar slug, e.g. "mi-comercio" (for href/push-url) panel_url_name -- URL name resolving to the panel endpoint panel_target -- id of the column-3 element the rows swap, no "#" {% endcomment %}
