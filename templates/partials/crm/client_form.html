{% comment %} The Crear/Editar cliente form -- the body of the shared client modal. One template for both, exactly like tag_dialog.html: with ``client`` it updates, without it creates. core.views.cliente_form renders it on GET and again on a rejected POST, so ``form`` always holds what the agent last typed and ``errors`` marks the fields to fix. The form targets the modal body itself: a rejected save lands right back here with the messages, and a successful one answers with client_saved.html, which closes the modal and swaps the table. ``q`` and ``page`` ride along as hidden fields so the refreshed table keeps the search and page the agent was on. Context: form, errors, client (or None), countries, channels, q, page {% endcomment %}
